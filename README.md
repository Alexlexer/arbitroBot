# Arbitrage Hub (Rust)

Высокопроизводительный бот для межбиржевого арбитража на бессрочных фьючерсах (Binance, Bybit, Bitget).

## Основные возможности
- **Real-time Matrix**: Мониторинг спредов между 3 биржами через WebSocket.
- **L2 Depth Guard**: Проверка стаканов для минимизации проскальзывания.
- **Telegram Control**: Интерактивное управление и уведомления о спредах > 5%.
- **Secure Auth**: Система входа по паролю для защиты бота.

## Быстрый старт (для клиента)
Если вы не разработчик, вы можете скачать готовые сборки:
1. Перейдите в раздел **Actions** вашего репозитория на GitHub.
2. Выберите последний успешный запуск (workflow: **Build and Release**).
3. В нижней части страницы (Artifacts) скачайте архив:
   - `arbit_hub_windows` (для Windows, внутри `.exe`)
    - `arbit_hub_linux` (для Linux, внутри `.deb` установщик)
2. **Автоматические релизы**: 
   - Каждый пуш в `main` автоматически обновляет релиз **"Latest Build"**.
   - Для стабильных версий создайте тег (например, `v0.1.0`), и будет создан отдельный именной релиз.

## Настройка
1. Создайте файл `.env` на основе [`.env.example`](.env.example).
2. Обязательно укажите:
   - `TELEGRAM_BOT_TOKEN` (токен от @BotFather)
   - `BOT_PASSWORD` (ваш секретный пароль для входа)

## Telegram Команды
- `/start` — Показать меню и Chat ID.
- `/login <пароль>` — Авторизация (необходима для получения алертов).
- `/status` — Текущее состояние системы.
- `/ping` — Простая проверка связи.
